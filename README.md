# Split sidebar［Firefox Floorp　add-on］
Firefox、Floorp用拡張機能。サイドバー・パネルサイドバーを分割表示します。

バージョン 0.6.1
※Firefox153ESRとFloorp12.20.2で動作確認済み。

特徴
・Firefox系
　サイドバーを上下分割して拡張機能やWEBページを表示することができます。
・Floorp系
　上記の機能の他にパネルサイドバーにも同じ機能が追加できます。

●注意点
・WEBページはPC用表示・スマホ用表示の選択式です。
　Floorpのパネルサイドバーのようにリンク先がメイン画面に飛ばないように制御するために
　一度、別ウィンドウで開いてから閉じる動作を行っています。
　リンクを押した際に一瞬、画面が別ウィンドウで表示されますが正常動作です。
・Split sideberに表示可能な拡張機能が一覧に表示されますが
　機能によっては表示できないものもあると思われますのでご注意ください。
